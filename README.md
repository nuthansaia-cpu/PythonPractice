# PythonPractice

A personal practice repository for learning Python fundamentals and improving day-to-day Git/GitHub workflow.

## Overview

This project contains small standalone Python scripts grouped by topic and challenge type:

- Conditions and operators
- Loops and control flow
- String operations
- List-based practice problems
- Weekly and weekend assignment challenges

## Tech

- Python 3.x
- No external packages required

## Run a script

From the repository root:

```bash
python3 hello.py
python3 section-14/Leap_year_Or_Not.py
python3 Section-15/Fibonacci_Series.py
python3 section-19/join_and_split.py
```

Notes:

- Many scripts are interactive and ask for input.
- Scripts are independent; there is no single main entry point.
